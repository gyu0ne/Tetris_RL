# 1대1 자기대전 r8: 공격력 일반화와 취약 상대 보정

## 1. 왜 r7을 바로 사용하지 않는가

r7의 공격형 모델을 실제 사용 속도인 12프레임/배치에서 다시 측정했다. 상대마다 64개의 새로운 시드를 사용했고 최대 4,000번 배치했으며 모든 게임이 종료됐다.

| 상대 | r7 승률 | r4 승률 | 변화 |
|---|---:|---:|---:|
| r4 직접 대전 | 54.7% | 기준 상대 | - |
| r3 update 700 | 28.1% | 45.3% | -17.2%p |
| r3 update 1050 | 48.4% | 34.4% | +14.1%p |

두 r3 상대에서 평균 공격량은 r4보다 약 10.0% 높았다. 그러나 r3 update 700에 대한 큰 약점 때문에 실사용 모델로 승격시키지는 않았다. r7은 공격 행동을 발견했지만 그 행동이 특정 상대에게만 강한 비순환적 전략으로 치우친 상태다.

세부 원본 결과는 `research/versus-r7-cadence12-final/`에 있고 요약은 `summary.json`이다.

## 2. r8의 학습 방향

r8은 r4로 되돌아가지 않고 r7 공격형 모델에서 시작한다. 공격 보상과 공격 준비 채널은 그대로 유지한다.

```text
정책 advantage = 표준화(
    1.0 × 생존·승패·방어 base
  + 2.0 × 공격 준비 setup
  + 3.0 × 실제 순송신 attack
)
```

r7의 base 가중치는 0.25였고 공격 성향을 만드는 데 성공했지만 상대별 취약성이 커졌다. r8은 base를 1.0으로 복구한다. setup과 attack의 합이 여전히 5.0이므로 공격이 주목적이라는 성격은 유지된다.

실제 공격 보상도 r7과 동일하다. 한 번에 많이 보내는 공격을 선호하는 제곱 효용과 최대 0.10의 bounded zero-sum 보상을 사용한다.

## 3. 취약 상대를 더 자주 학습하는 방법

전체 32게임 중 약 85%를 역사 모델과 대전한다. 역사 상대 선택의 70%는 현재 모델이 가장 어려워하는 상대를 우선하는 hard PFSP이며, 난이도 가중치를 제곱한다. 따라서 r3 update 700처럼 승률이 낮은 상대가 자동으로 더 자주 선택된다.

- 현재 모델끼리 대전: 10%
- 역사 모델: 85%
- 솔로 모방 모델: 5%
- 역사 모델 내부: balanced 20% / hard 70% / uniform 10%

uniform 10%는 다른 전략을 완전히 잊는 것을 막고, balanced 20%는 승률이 비슷해 학습 신호가 풍부한 상대를 유지한다.

## 4. 실행 방법

작업 트리가 커밋된 상태에서 실행한다.

```powershell
./scripts/run-versus-offense-generalization-r8.ps1 -ResourceProfile max
```

기본 실행은 누적 업데이트 25, 50, 75, 100, 125, 150에서 저장하고 검사한다. 중단한 뒤 같은 명령을 실행하면 기존 `latest.pt`에서 이어진다.

주요 위치:

- 설정: `configs/training/versus_selfplay_ppo_r8.json`
- 체크포인트: `checkpoints/versus-selfplay-r8/`
- 단계별 검사: `checkpoints/versus-selfplay-r8/probes/`
- 최종 결과: `checkpoints/versus-selfplay-r8/selection-report.json`
- 최종 선택본: `checkpoints/versus-selfplay-r8/selected-model.pt`

## 5. 최종 승격 기준

이번 프로젝트의 실제 사용 조건인 12프레임/배치에서만 최종 판정한다.

- r4 대비 평균·최악 상대 승률 저하가 2%p 이내
- r4 직접 대전 승률 50% 이상
- r4보다 평균 순송신 공격량 5% 이상 증가
- 위험 구간 비율 1.50배 이하
- 홀 수 1.25배 이하

공격량 5% 기준은 낮춰 잡은 임의 수치가 아니다. 재평가된 r7의 증가량은 약 10%였으므로, r8이 그 공격량의 약 95% 이상을 보존하려면 r4 대비 약 5% 증가가 필요하다. 모든 기준을 통과하지 못하면 기존 r4가 `selected-model.pt`로 유지된다.
